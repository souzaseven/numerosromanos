# 🔢 Conversor Decimal ↔ Romano

<img src="https://github.com/souzaseven/numerosromanos/blob/Desafios/numbersromanos.png?raw=true" width="50%" alt="Preview">

Conversor bidirecional entre números decimais e algarismos romanos com interface intuitiva e funcionalidades avançadas.

## ✨ Funcionalidades Principais

### 🔄 Conversão Bidirecional
- **Decimal para Romano**
  - Suporte a números de 1 a 3999
  - Conversão automática durante a digitação
- **Romano para Decimal**
  - Validação de algarismos romanos
  - Detecção de formatos inválidos

### 🛠 Ferramentas Integradas
| Recurso | Descrição | Ícone |
|---------|-----------|-------|
| Copiar resultado | Copia o resultado para área de transferência | 📋 |
| Limpar campos | Reseta todos os campos | 🗑️ |
| Tabela de referência | Mostra valores básicos | 📊 |
